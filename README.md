# Sport and Healing

Telegram-бот для поиска спортивных и оздоровительных секций без ограничений по видам спорта и городам.  
Проект поддерживает все города Казахстана и России.

---

## About

Sport and Healing — это Telegram-бот, который помогает пользователям находить спортивные и оздоровительные секции по выбранному городу и виду активности.  
Бот ориентирован на простой интерфейс, отсутствие ограничений и возможность дальнейшего расширения.

---

## Features

- Поддержка всех городов Казахстана и России  
- Любые виды спорта и оздоровительных направлений  
- Пошаговый выбор: страна → город → направление  
- Просмотр доступных секций  
- Возможность изменить выбор в любой момент  
- Простой и понятный интерфейс  

---

## How It Works

1. Пользователь запускает бота командой `/start`
2. Выбирает страну
3. Выбирает город
4. Выбирает вид спорта или оздоровительное направление
5. Получает список доступных секций
6. Просматривает подробную информацию

---

## Supported Regions

- Россия — все города

- Swimming  
- Tennis  
- Athletics  
- Fitness

- Rehabilitation  
- Esports  

Список не ограничен и может быть расширен.
